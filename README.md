### 🛠️ Featured Projects

* **AniCore Geomechanics Suite (*Currently Private*):** An end-to-end interactive Streamlit application built for anisotropic (VTI) geomechanical modeling, core-to-log calibration, and predictive analysis in uncored wells intersecting VTI shales[cite: 2]. Features include automated stiffness tensor calculations ($C_{11}, C_{13}, C_{33}, C_{44}, C_{66}$), dynamic-to-static moduli conversions, in-situ VTI stress profiling, multi-well log imputation, and hyperparameter-tuned ML models (`GridSearchCV` Gradient Boosting Regressors) to predict **static mechanical properties** where core data is absent[cite: 2].
* **Drilling Optimization App:** An interactive web tool built with Streamlit, NumPy, SciPy, and Matplotlib[cite: 1]. It operationalizes classical cost-per-foot economic models and rate-of-penetration empirical relationships, enabling real-time weight-on-bit (WOB) and rotary speed (RPM) optimization using BFGS numerical solvers[cite: 1].
